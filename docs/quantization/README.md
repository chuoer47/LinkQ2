# 量化体系与离线包

本专题分为三篇，先解释量化方案，再说明如何生成和使用产物。

1. [W4A16 量化方案与算法](01-w4a16.md)：分组对称与非对称量化、RTN / RTN-Clip / AWQ / AWQ-Affine，以及策略选型。
2. [KV4 量化方案与算法](02-kv4.md)：SmoothAttention、K 的静态逐通道量化、V 的动态逐 token 分组量化，以及差异化设计的原因。
3. [量化包设计、字段与使用](03-checkpoint.md)：离线生成流程、完整 checkpoint 协议、命令与 Python 用法、独立加载和验证。

W4A16 量化的是模型参数，离线生成完整 checkpoint。KV4 量化的是推理过程中生成的 K/V 缓存：离线只生成平滑因子和静态 K scale，K/V 整数在运行时写入缓存。因此 KV4 属于本项目量化体系，但不属于 W4A16 checkpoint 的生成步骤。

两者可以分别启用：浮点权重 + FP16 KV、W4 权重 + FP16 KV、浮点权重 + KV4、W4 权重 + KV4。使用 KV4 时额外提供对应模型的校准文件。

算法和协议以项目代码为准；本专题不展开算子调度、Runtime 调度和投机算法实现，这些内容在其他专题中整理。
