## 1. 精度评测（PPL）

| 用途 | 数据集 | 口径 |
|---|---|---|
| 主精度指标 | **WikiText-2 raw**（test split） | 业内标准（GPTQ/AWQ/KIVI/QServe 论文口径），滑窗 stride 512 |
| 辅助精度指标 | C4（en，val 抽 256 条） | 防"单数据集过拟合"质疑 |
| 校准集（量化用） | C4 train 抽 128 条 × 2048 tokens | 与评测集**不同源不同 split**（红线） |

**校准集冻结**：首次生成后存 `results/frozen/calib_c4_128x2048.pt`（token id），M1 量化器、M2 KV4、M4 组合全部只读此文件，任何阶段不得重新生成。

## 2. 长上下文评测

- **方案：NIAH（大海捞针）自实现**（~100 行，不依赖外部 benchmark 仓库）
  - 随机 uuid 式 key-value 对（不可猜），needles 数量/深度可调
  - 指标：各深度 × 各长度召回率（%）
- 分两档：
  - **32K 档（必做，M2/M4）**：Qwen3-8B 原生窗口，KV4 vs FP16 精度无损性验证
  - **128K 档（M4 demo）**：YaRN rope_scaling（factor=4.0），跑通即成功，不做全深度扫描
- RULER/LongBench 列为可选扩展，不进主线。

## 3. 性能评测

### 3.1 指标定义

| 指标 | 定义 |
|---|---|
| 主指标 | **batch=1 decode throughput (tokens/s)**：input 512 tokens 固定 + decode 128 tokens，取后 100 tokens 均值（去 warmup） |
| kernel 级指标 | GEMM kernel 独立 benchmark（`kernels/csrc/test_*.cu`），M/N/K 用 Qwen3-8B 真实形状（如 4096×4096） |
| M3 特有 | acceptance rate（每步平均接受 draft token 数）+ γ 扫描（1~6） |

### 3.2 测量纪律（写进 bench 脚本）

- 锁最空 GPU（`CUDA_VISIBLE_DEVICES`），开测前 `nvidia-smi` 快照存进结果 json
- 每配置 **5 轮取中位数**，同时报 std
- 对照组（vLLM FP16 / AWQ-Marlin）同卡同时段实测，**绝不引用论文数字当基线**

### 3.3 结果格式

每个 bench 输出 json 至 `results/`（时间戳 + gpu 快照 + torch/驱动版本），markdown 表格由脚本从 json 生成——数字可追溯。

> 共享服务器噪声：不作为协议条款。实际测量时挑空卡时段即可（用户指示）。

## 4. 里程碑验收标准（及格线，非目标值；实际按能打多好打多好）

| M | 验收标准 |
|---|---|
| M0 | 1.7B FP16：PPL 与 transformers 参考实现**误差 <0.1**（正确性 oracle）；tokens/s 记录基线 |
| M1 | W4A16：PPL 相对 FP16 **劣化 <0.3**（group=128）；kernel 吞吐 ≥ FP16 cuBLAS **1.3×**（decode 区间）；与 AWQ 官方量化模型 PPL 差距 <0.2（算法对齐） |
| M2 | KV4：PPL 劣化 <0.5（相对 FP16 KV）；KV 显存**省 ≥3.5×**；32K NIAH 召回率降幅 <5% |
| M3 | 投机推理：**无损性测试通过**（固定 seed 下与 target-only 采样 token 序列一致率 >99%，允许浮点非确定性）；acceptance rate ≥2 时端到端加速 ≥1.5× |
| M4 | 8B 组合：四方对比表（FP16 / W4A16 / W4A16+KV4 / +Spec）；32K NIAH 全通过；128K YaRN demo 跑通 |

**叠加口径（已确认接受）**：M1（<0.3）与 M2（<0.5）的 PPL 劣化线为**叠加关系**，M4 组合预期合计 <0.8。验收线的意义是最低可交付，非设计目标。
