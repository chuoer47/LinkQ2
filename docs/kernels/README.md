# Kernel 设计

这一专题解释权重与缓存采用低位表示后，GPU 上的计算怎样组织，以及这些组织方式为什么适合不同工作量。

- [W4A16：压缩权重的矩阵计算](01-w4a16.md)：从权重流量与输入复用出发，解释 GemLite 的打包布局、块内反量化、GEMM、Split-K 和单行 RevSplit-K，以及项目接入时的取舍。
- [KV4：整个 Attention 怎样围绕压缩缓存工作](02-kv4-attention.md)：从每层的数据流出发，解释缓存写入、分页寻址、流式 softmax、单行 decode、多位置 verify，以及 prefill 与 FlashAttention 的组合。
- [正确性、精度与性能怎样验证](03-validation.md)：说明怎样区分量化误差与执行误差，怎样检查因果范围和物理地址，以及不同测量能回答什么问题。

两类算子都希望少搬运数据，但工作量不同：W4A16 消费固定权重，Attention 消费不断增长的缓存；输入行数、可复用的数据和归约方式也随之不同。阅读时可以围绕四件事理解：数据保存在哪里、一次程序负责什么、哪些结果被重复利用、并行计算最后如何合并。

文中在具体设计旁给出源码入口。量化整数、尺度和校准方法见[量化专题](../quantization/README.md)；请求调度、缓存页生命周期和 Graph 编排见 [Runtime](../runtime/README.md)。
