# CUDA Graph 实测结果

2026-10-16，RTX 4090 D GPU 1，Qwen3-8B；代码 `819daa7`。四个独立进程，128/512 输入、16 输出，预热一次、三次取中位数。复用既有 HF 参考；未重新量化、校准，未修改 GemLite 或 KV4 算子的计算实现。

原始数据：`results/cuda_graph/2026-10-16/`。两组 graph 均实际 replay 211 次，生命周期与释放检查通过。

## 数值结果与限制

FP16 的 graph/eager 48 个配对位置 logits 完全相同。W4+KV4 的相对 L2 为 0.136464、top1 一致率 93.75%，**未通过严格等价关卡**；`summary.json` 保留 `passed=false`，入口以非零退出。不能将其描述为无损等价加速。

随后在同进程固定权重、配置与参考历史，额外重复运行，结果如下。一次性诊断脚本保存在仓库外，原始数据为 `repeatability.json`。

| 对照 | logits 相对 L2 | top1 一致率 |
|---|---:|---:|
| eager / eager | 0.116265 | 93.75% |
| graph / graph | 0.133742 | 95.83% |
| eager / graph | 0.129499 | 95.83% |

单独抽取 `[M,N,K]=[1,4096,4096]` 的 W4 q_proj，对相同输入重复 16 次，仅首次结果与自身逐位相同；最大配对相对 L2 为 0.001307，最大绝对差 0.015625，见 `linear_repeatability.json`。现有 GemLite GEMV 使用 FP16 输出的 `tl.atomic_add`。单算子已有重复性波动，W4+KV4 的全链路也不严格确定；其误差放大机制没有进一步逐层归因。

本轮保持算子计算不变、严格关卡不放宽。FP16 graph 接入验收通过；W4+KV4 的速度、显存和数值差异均完成测量，但严格一致性仍未通过。默认一键入口会在此关卡失败时保留报告并返回非零。

关闭后 eager/graph 分别保留 8.125/16.250 MiB cuBLAS 工作区，与各自预初始化的普通流、捕获流基线一致；模型、KV 与 graph 张量已释放。
